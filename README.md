# 微信公众号爆款标题生成器

通用 AI Prompt / Skill — 用于生成和优化微信公众号文章标题，最大化打开率。

## 最新更新

- **v2.0** — 新增 **AIDD / 医药行业深度方法论**，覆盖 7 大专属标题公式、AIDD 专属词汇库、禁忌清单
- 其他行业保留通用适配指南

---

## 功能

| 模块 | 说明 |
|------|------|
| 5 大爆款公式 | 悬念式 / 数字式 / 对比式 / 痛点式 / 权威背书式 |
| AIDD 深度方法论 | 7 大专属公式（管线里程碑/方法学对比/不可成药靶点突破/大药企实践/反直觉发现/学术工业鸿沟/交易格局），含专属词汇库和禁忌清单 |
| 高点击词汇库 | 6 类通用情绪词 + AIDD 专属专业词汇 |
| 分领域适配 | AIDD/医药（深度）+ 科技/教育/职场/健康/金融 简要指南 |
| 5 步执行流程 | 理解内容 → 选公式 → 出候选 → 优化 → 交付 |

## 安装 / 使用方式

### 方式一：直接使用（推荐）

将 `SKILL.md` 的内容**直接粘贴**到任意 AI 对话框（ChatGPT / Claude / DeepSeek / 元宝等），AI 即可按框架生成标题。

### 方式二：WorkBuddy Skill

```bash
mkdir -p ~/.workbuddy/skills/wechat-viral-title
cp SKILL.md ~/.workbuddy/skills/wechat-viral-title/
```

安装后，在 WorkBuddy 对话中说：
- "帮我起个标题"
- "这个标题怎么改"
- "生成几个公众号标题方案"

### 方式三：Cursor / Windsurf 规则

将 `SKILL.md` 内容添加到项目规则文件，让 AI 在写作时自动遵循标题策略。

## AIDD / 医药行业示例

输入：一篇关于 AlphaFold 3 在靶点发现中应用的分析文章

输出 5 个候选标题：
1. AlphaFold 3 放开代码了，但做虚拟筛选的人发现了 3 个坑（反直觉发现式）
2. 同一个 GPCR 靶点，传统方法筛了 5 年，AF3 两周给出结构（方法学对比式）
3. KRAS G12D：第一个 AI 发现的非共价抑制剂，长这样（不可成药靶点突破式）
4. 诺华内部报告：生成式 AI 在 hit finding 中的真实表现（大药企实践深挖式）
5. 大家都认为分子对接已解决，但 FEP+ 说还有 40% 的误差（学术工业鸿沟式）

## 通用示例

输入：一篇关于学英语方法的文章

输出 5 个候选标题：
1. 背了 3 年单词还是忘？可能你犯了这个错误（痛点+悬念）
2. 99% 的人学英语方式都错了，第 3 条最关键（数字+痛点）

4. 别再乱花钱买课了，学英语最快的方法就一个（痛点+紧迫）
5. 斯坦福研究：高效学外语的秘密，原来这么简单（权威+悬念）
