# 微信公众号爆款标题生成器

一个可复用的 AI Prompt / Skill，用于生成和优化微信公众号文章标题，最大化打开率。

## 功能

- **5 大爆款公式**：悬念式 / 数字式 / 对比式 / 痛点式 / 权威背书式（含模板 + 示例）
- **高点击词汇库**：6 类情绪词，覆盖好奇 / 恐惧 / 惊讶 / 后悔 / 稀少 / 权威
- **排版与结构技巧**：标点运用、截断测试、分段策略
- **五大禁忌清单**：避免标题党、泛泛而谈、无情绪表达
- **分领域适配**：科技 / 教育 / 职场 / 健康 / 金融 各一套策略
- **5 步执行流程**：理解内容 → 选公式 → 出候选 → 优化 → 交付

## 使用方法

### 方式一：作为 AI Prompt 使用

将 `SKILL.md` 的内容直接粘贴到 ChatGPT / Claude / DeepSeek / 元宝 等任意 AI 助手中，然后输入你的文章主题，AI 会按照框架生成候选标题。

### 方式二：作为 WorkBuddy Skill 安装

```bash
mkdir -p ~/.workbuddy/skills/wechat-viral-title
cp SKILL.md ~/.workbuddy/skills/wechat-viral-title/
```

### 方式三：作为 Cursor / Copilot 规则

将 `SKILL.md` 放入项目中的 `.cursor/rules/` 或 `.github/copilot-instructions.md`。

## 触发示例

对 AI 说：
- "帮我起个公众号标题，文章是关于学英语方法的"
- "这个标题怎么改：如何提高工作效率"
- "生成 5 个科技类公众号标题方案"

## 输出示例

输入：一篇关于学英语方法的文章

输出 5 个候选标题：
1. 背了 3 年单词还是忘？可能你犯了这个错误（痛点 + 悬念）
2. 99% 的人学英语方式都错了，第 3 条最关键（数字 + 痛点）
3. 为什么有人两周背完 1000 词，你背了两年还在第一页？（对比 + 悬念）
4. 别再乱花钱买课了，学英语最快的方法就一个（痛点 + 紧迫）
5. 斯坦福研究：高效学外语的秘密，原来这么简单（权威 + 悬念）
